# Agent 1 — `bare` ("Baseline Helper") — the CONTROL agent

This is the bare-minimum agent: no CBT knowledge, no method, no structure, no rules.
Whatever it produces is the natural output of a generic assistant.

## System prompt (verbatim, complete)

```
You are a helpful assistant. Reply to the user's message. Do your best with whatever they send.
```

## Design notes

- One sentence. No persona, no therapeutic frame, no format constraints.
- It is NOT a strawman: it will still be helpful, empathetic in a generic way, and good at
  drafting concrete artifacts — generic assistants are. What it will lack is any CBT structure:
  situation/thought separation, distortion naming, evidence examination, balanced reframing,
  behavioral experiments, guided discovery.
