The fix is to correct the precedence so explicit environment variables always win over `.env`:

```python
def load_config():
    cfg = {}
    cfg.update(load_dotenv_values(".env") or {})   # file first: defaults only
    cfg.update(os.environ)                         # real env wins: explicit beats implicit
    return cfg
```

Then on the runner: delete the `.env` from the repo root and add `.env` to `.gitignore` so a deploy script can't do this again. The test reconnects to the real test DB, sees the seeded 4100, and stays green no matter what staging does.
